O‘rnatish

O‘rnatuvchi yo‘q — ZIPni oching va ishga tushiring. Butun papka kerak, faqat bitta fayl emas.

macOS · Apple Silicon
  1. Python 3.11+ kerak: python.org dan o‘rnating.
  2. ZIPni oching va papkani ~/Projects ga qo‘ying (iCloud sinxronlanadigan Desktop’ga emas).
  3. MusicPro.command ustida o‘ng tugma → Ochish (faqat birinchi safar).
  4. Dastur brauzerda ochiladi. Yopish — ichidagi “Chiqish” tugmasi.
Windows 10/11 · x64
  1. ZIPni to‘liq oching (Python va FFmpeg ichida).
  2. MusicPro.exe ni ishga tushiring.
  3. SmartScreen chiqsa: Batafsil → Baribir ishga tushirish.
  4. Tekshiruv uchun TEKSHIRISH.bat.
